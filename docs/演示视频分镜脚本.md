## 1. 录制前检查清单（每次开录前过一遍）

- [ ] 两台模拟器已启动，**窗口宽度调至一致**，任务栏/桌面杂物不入镜
- [ ] Windows 开启**专注助手（勿扰）**，关闭微信/QQ 弹窗
- [ ] A 实例：岛屿「绿屿」阶段、明细 95 笔；B 实例：生态值 96.5kg（已就绪，勿清空）
- [ ] OBS 先录 10 秒试播：确认无鼠标残影、无卡顿掉帧
- [ ] 每个分镜**单独录一条**（sceneXX.mp4），拍错只重拍该镜
- [ ] 操作放慢 20%：点击后停 1 秒再看结果，toast 停留 2 秒
- [ ] 匿名检查：画面/文件名/浏览器不得出现学校、姓名、团队信息

## 3. 逐镜详细脚本

### S0 片头（6s）· A+B 并排
- **画面**：双模拟器并排，岛屿页面；叠加白字标题「零屿 Zero Isle — 把每一次低碳选择，变成一座看得见生长的岛屿」；角标「赛题二 · 参赛作品演示」
- **解说**：「零屿，一款基于 OpenHarmony 的碳足迹记录应用。你的每一次绿色行为，都会变成一座看得见生长的岛屿。」

### S1 岛屿主页·生长仪式（22s）· A 窗口（首界面，必拍好）
| 步骤 | 操作 | 画面重点 |
|---|---|---|
| 1 | 岛屿主页静止 3 秒 | 绿屿场景动画：云、海浪、树木、码头小船 |
| 2 | 展示生态值进度条（88.1kg / 距森屿 61.9kg）+ 三数据卡 | 核心数据总览 |
| 3 | 岛灵建议卡扫过 | 个性化 |
| 4 | 快捷输入「光盘」→ 解析 → 记录 → **镜头停在岛屿上 2 秒** | **双波纹扩散 + 增益浮字 + 生态值上涨**（生长仪式感，本片记忆点） |
- **解说**：「打开零屿，首先是一座属于你的岛。每一次低碳行为都会化作生态值，推动岛屿从灰屿、青屿、绿屿一路长成生态屿——这就是坚持的全部意义。」

### S2 低碳行为核算（36s）· A 窗口
| 步骤 | 操作 | 画面重点 |
|---|---|---|
| 1 | 「记」页，四个 AI 入口按钮上扫过 | 拍照识别/相册识别/电表抄表/扫码录入 |
| 2 | 点「绿色出行」→ 点「骑行代替驾车」→ 数量输 3 | 因子 0.20 kg/公里 + 口径说明入镜 |
| 3 | 点「记录」 | 实时预览「0.60 kg / +6 币」→ toast |
| 4 | 「我的 → 记录明细」 | 按日分组卡片 + 当日小计 |
- **解说**：「应用内置 5 大类 30 项排放因子，每项都标注取值口径；手动选择、一句话语义、拍照识别、扫码等七种录入方式，减排量自动核算、实时折算岛币。所有记录按天分组，可逐条追溯。」

### S3 数据可视化看板（30s）· A 窗口
| 步骤 | 操作 | 画面重点 |
|---|---|---|
| 1 | 「析」页 | 减排趋势折线图（近 7 天） |
| 2 | 周期胶囊切「近 6 个月」→ 回「近 7 天」 | 图表形态随周期切换 |
| 3 | 点分类筛选「绿色出行」 | 趋势图联动只统计该分类 |
| 4 | 下滑到「分类减排占比」饼图 + 「碳画像雷达」 | 饼图点击扇区下钻 → 明细 → 返回 |
| 5 | 「你的减排相当于…」等价物换算 | 少开车/种树/节电 |
- **解说**：「看板提供折线图、柱状图、饼图与雷达图，四种周期口径，支持按分类筛选并一键下钻到逐条明细；减排贡献还会换算成少开车公里数和种树棵数。」

## 5. 剪辑与导出规范

1. 镜头间硬切；每段开头可加 0.3s 放大转场；**不要**花哨特效
2. 关键数字上字幕并放大：`0.60 kg`、`+20 岛币`、`1375 分 · 110.1 kg`、`POST /v1/points/sync`
3. S1 的波纹动画与 S7 的双窗口是全片两个记忆点，剪辑时给足停留时间
4. 背景音乐选轻快无版权曲，音量压到解说之下
5. 导出：1080P / 30fps / H.264 / 码率 2.5Mbps → 预估 90MB < 100MB ✓
6. 成片命名按大赛要求放入压缩包（外层命名含学校团队信息，视频文件本身**不含**）

## 6. 匿名与合规红线

- 视频画面、文件名、字幕中**不得出现**学校、院系、团队、指导老师、真实姓名
- 录制前关闭浏览器书签栏、清理桌面与最近文件列表
- 收尾不放 GitHub 等任何外部链接
- 视频时长 ≤5:00、≤100MB，MP4 格式
