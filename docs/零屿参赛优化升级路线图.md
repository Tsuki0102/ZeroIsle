## 1. 项目现状总览（体检结论）

**产品定位**：「零屿 = Zero + Isle」，低碳行为量化养成游戏——每笔减排让 Canvas 岛屿从灰屿生长为生态屿，数据叙事完整、无云依赖，隐私友好。

**架构与导航**：

```
EntryAbility → Index（5 Tab：屿/记/析/营/验）
  屿 IslandPage      — Canvas 五时五岛 + 玻璃卡 + 一句话语义录入
  记 RecordPage      — 5 类行为录入 + 拍照 OCR + 电表抄表（Core Vision Kit）
  析 StatsPage       — 日/周/月/年趋势 + 环图 + 雷达 + 等价物换算
  营 TaskPage        — 每日任务/周挑战 + 徽章墙 + 岛币商城 + 通知
  验 LabPage         — 3 个互动计算器 + 4 篇双碳科普
二级页：碳账单海报 PosterPage / 岛屿图鉴 DexPage / 宿舍周榜 WeekRankPage /
        备份导出 BackupPage / 碳普惠 CarbonPlusPage / 设置 SettingsPage
桌面卡片：ZeroIsleCard(2x2) ← EntryFormAbility 直读 RDB
数据层：relationalStore（zeroisle.db，33 因子 × 5 大类）+ 语义解析器 + 演示数据生成器
```

**功能对照赛题**（主要功能 5 项全部覆盖 ✅，创新拓展 4/4 ✅ 全部完成）：

| 赛题要求 | 状态 | 说明 |
|---|---|---|
| ① 低碳行为核算 + 因子库 | ✅ | 33 因子、5 大类、口径 tip；5 条录入通道 |
| ② 可视化看板 | ✅ | 零依赖自绘折线/柱状/环图/雷达，日/周/月/年切换 |
| ③ 碳积分激励 | ✅ | 3 日常 + 4 周任务、8 徽章、商城、1kg=10 币 |

### O2 右上角头像点击无反应（`IslandPage` 等）
- **现象**:首页右上角个人中心小圆点点击无反应(此前可正常进入「我的」)。
- **定位**:用 `uitest dumpLayout` 导出 UI 树,发现头像节点 `Stack`（bounds `[1128,237][1260,369]`,`clickable:true`）之上叠加了两个**装饰性波纹** `Column`（bounds 覆盖到 `[61,117][1258,956]`、`opacity:0`、`hitTestBehavior:Default`），把头像的点击吞掉了。
- **根因(回归)**:在「L 包 API24 兼容修复」中把波纹由 `Circle()` 改为 `Column()`。`Circle()` 的命中区是**圆形几何**（不压住头像），而 `Column()` 的命中区是**矩形**（覆盖了头像）——即"为消除 SDK26 告警而引入的点击回归"。
- **修复**:给所有**纯装饰**圆形加 `.hitTestBehavior(HitTestMode.None)`:
  - `IslandPage` 双波纹 ×2、引导圆点;

## 17. 追加包 Q：跨页刷新失效根因修复（2026-09-23）

> 反馈:首页「解析 → 确认记录」后,首页数据不增加。

- **定位手段(数据说话)**:把设备上的 `zeroisle.db`（含 `-wal`）拉到本地,用 **Python `sqlite3`** 直查 → `behavior_record` **确实有 1 条**（`E01 节电2度 → 1.14kg`,`source='语义'`,`points=11`,`record_date=今天`）,而首页当时显示 `0.0` → 结论:**入库成功,只是首页没刷新**。
- **根因**:`emitter.off(EVT_DATA_CHANGED)` 用的是**单参数**形式。该 API 语义是"移除该 eventId 的**全部**订阅";而全站有 **6 个页面**（`IslandPage` / `RecordPage` / `StatsPage` / `TaskPage` / `MinePage` / `DexPage`）都在 `aboutToDisappear` 里这样写 → **任一页面销毁都会把其它页面的监听一并清除**,此后数据变更广播收不到,页面长期停留旧数据。
- **修复**:改为「保存回调引用 + 两参数退订」,各页只移除自己的订阅:
  ```ts
  private readonly onDataChanged: () => void = () => { this.loadXxx() }
  emitter.on({ eventId: EVT_DATA_CHANGED }, this.onDataChanged)
  emitter.off(EVT_DATA_CHANGED, this.onDataChanged)   // 只退订自己
  ```
  覆盖上述 6 个页面。
- **验证(模拟器)**:重装后首页正确显示 **生态值 1.1kg / 今日减排 1.14kg / 可用岛币 11 分 / 连续打卡 1 天**,与数据库完全一致（截图 `shots/fix_home3.jpeg`）。
- **编译验证**:`assembleHap` **BUILD SUCCESSFUL**。

### ⚠️ 修复的 ArkUI 渲染硬伤（本次最关键的坑）
初版把「胶囊/结果面板/主按钮/指标」抽成**带参 `@Builder`**（如 `pill(label, active, onTap)`）。实测发现：**ArkUI 中带参 @Builder 为按值传递，不会随状态变量刷新**——点「驾车」后选中态、结果面板、按钮全部不变化，交互等于失效。
**修复方案**：全部改为**无参 `@Builder`**（等价于内联 UI，状态读取可正常驱动刷新），并把动态内容内联进各区块组件；仅参数恒定不变的 `toolHead(icon,title,tag)` 保留入参。修复后：切换出行方式、点常用预设、记账成功、切换分类、收藏、展开正文**全部即时刷新**。
