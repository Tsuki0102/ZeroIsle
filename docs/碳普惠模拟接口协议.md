# 豫碳分 · 城市碳普惠开放平台 接口协议（模拟层 v1.0）

> 零屿 App 与城市碳普惠平台对接的协议设计文档。当前版本以「本地协议模拟层」实现（无真实网络），接口形态、报文结构、时序与正式版完全一致，正式接入时仅需将 `CarbonPlusPage` 中的模拟调用替换为 HTTP 客户端（@kit.NetworkKit 的 `http` 模块）。

## 1. 通用约定

- 传输方式：HTTPS（正式版）；Content-Type: `application/json; charset=utf-8`
- 鉴权：OAuth 2.0 授权码模式。App 端拉起平台授权页 → 换取 `access_token`（有效期 7200s）→ 后续请求携带 `Authorization: Bearer {token}`
- 响应统一信封：

```json
{ "code": 0, "msg": "ok", "data": { } }
```

- 错误码：`0` 成功；`401` 未授权；`1001` 账本校验失败；`1002` 积分不足；`1003` 权益库存不足

## 2. 接口清单

### 2.1 授权换 token（模拟层内置约定）

```
POST /v1/oauth/token
Request:  { "grant_type": "authorization_code", "code": "本地授权模拟码", "account": "local" }
Response: { "code": 0, "data": { "access_token": "ZPT-****", "expires_in": 7200 } }
```

### 2.2 积分同步（对应 App「同步积分到平台」）

```
POST /v1/points/sync
Request:  { "account": "local", "points": 917, "ledger_hash": "sha256(本地账本摘要)" }
Response: { "code": 0, "msg": "accepted", "syncId": "ZPS-260914" }
```

- 平台侧幂等：以 `ledger_hash` 去重，重复上报不叠加
- App 侧：成功后记录 `last_sync` 时间戳（kv: `carbonplus_last_sync`）

### 2.3 权益兑换（对应 App「碳积分权益兑换」）

```
POST /v1/benefits/redeem
Request:  { "item": "公交 5 元乘车券", "cost": 100 }
Response: { "code": 0, "voucher": "ZP-12345" }
```

- 平台侧扣减积分并核销权益库存；App 侧把 `voucher` 呈现给用户并记录兑换流水（`exchange_log`）

### 2.4 家庭账本合并（对应 App「家庭碳积分合并」）

```
POST /v1/family/merge
Request:  { "members": [ { "account": "A", "points": 917, "co2": 90.2 }, { "account": "B", "points": 420, "co2": 41.0 } ] }
Response: { "code": 0, "familyId": "FAM-77", "totalPoints": 1337, "totalCo2": 131.2 }
```

- 模拟层落地方式：家庭成员间通过「积分包」JSON 文件交换（`zeroisle-family-*.json`），App 本地合并统计；该文件级交换协议与 2.4 报文结构一一对应
- 预留：同一华为账号多设备场景下，可平滑切换为端侧分布式数据库（KVStore）同步，无需改动统计口径

### 2.5 对账单查询（规划中）

```
GET /v1/bill?month=2026-09
Response: { "code": 0, "data": { "synced": 917, "redeemed": 100, "items": [ ... ] } }
```

## 3. 调用时序

```
App                          平台(模拟层)
 │  POST /v1/oauth/token       │
 │────────────────────────────▶│  颁发 access_token
 │  POST /v1/points/sync       │
 │────────────────────────────▶│  ledger_hash 幂等校验 → 受理
 │◀─────────────── syncId ─────│
 │  POST /v1/benefits/redeem   │
 │────────────────────────────▶│  扣减积分 → 核销权益
 │◀─────────────── voucher ────│
 │  每次调用在「接口调用日志」留痕(时间/接口/请求/响应)
```
