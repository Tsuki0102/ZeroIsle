# 真机拍摄作战手册（借机 1 小时版）

> 目标：用借来的真机补齐模拟器无法演示的两类素材——**端侧 OCR 识别**与**双机分布式同步**。
> 其余功能模拟器已全部可演示，真机素材是锦上添花。

## 一、借机前的准备（在自己电脑上提前完成，约 15 分钟）

1. **签名配置**（真机拒绝未签名包，必须做）：
   DevEco Studio → File → Project Structure → Signing Configs → 勾选
   *Automatically generate signature* → 登录任意华为账号 → OK → 重新 Build。
2. **构建安装包**：Build → Build Hap(s)/APP(s) → Build Hap(s)，产物在
   `entry/build/default/outputs/default/entry-default-signed.hap`。
3. **传输通道**：确认能把文件传进对方手机（微信文件传输助手最通用）。
4. **演示账号**：注册一个全新华为账号（双机登录用，不混用个人账号）。
5. **样例图**：把 `entry/src/main/resources/rawfile/` 下的
   `meter_sample.jpg`、`guangpan_sample.jpg`、`bike_qr_sample.png` 通过微信发到自己，
   借机时转存进对方手机相册。

## 二、借到手机后的 10 分钟准备

1. 开发者选项：设置 → 关于手机 → 连点"软件版本" 7 次 → 返回打开 **USB 调试**（可选，走 hdc 安装更稳）。
2. 安装应用：微信收 HAP → 文件管理器点击安装；或 USB 连接后 `hdc install -r xxx-signed.hap`。
3. 首启：跳过引导 → 「我的」→ **生成演示数据**（每台都做，让账本饱满）。
4. 若拍双机分布式：两台手机**登录同一个演示华为账号** + **同一 Wi-Fi**；
   首次打开「碳普惠平台」页会弹多设备协同授权，点允许。

## 三、拍摄清单（按优先级排序）

### A. 双机分布式同步（真机专属，最优先；需两台手机，约 10 分钟）
1. 两台手机都打开「我的 → 碳普惠平台」，确认页顶显示"分布式 KV 已接入"。
2. 甲点「同步到超级终端」；乙等 3-5 秒 → "已连接设备 2" 与合计减排自动出现。
3. **关键镜头**：甲在「记」页录一笔新行为（如骑行 3 公里），
   乙不操作，屏幕上"跨设备合计减排"数字自动上涨——这是创新①的核心证据，务必录到。

### B. 拍照识别 / 电表抄表 OCR（真机专属，约 10 分钟）
1. 「记」→ 拍照识别 → 对准相册里的 `meter_sample.jpg`（另一台设备显示该图即可）或真实电表。
2. 识别出读数 → 输入上次读数 → 记录 → 看板/明细同步出现。
3. 电表抄表：相册选图 → 识别 → 录入。

### C. 扫码录入（真机更顺滑；模拟器也可拍）
对准 `bike_qr_sample.png` → 自动解析公里数 → 记录。

### D. 真机加分镜头（时间富余再拍）
- 任务完成 → 领取岛币；商城兑换植树证书；岛灵对话一句话记账；海报生成与分享。

## 四、拍摄要点

- 用系统**屏幕录制**（下拉快捷面板），分辨率调最高；竖屏、电量 >50%、开勿扰。
- 每个动作放慢 20%，点击后停顿 1 秒再展示结果。
- 双机同框镜头：两台手机并排放在桌上，一台录屏 + 一台用另一设备拍全景（体现"两台设备"）。
- 素材命名：`real_ocr.mp4`、`real_sync.mp4`、`real_qr.mp4`…，拍完发我剪辑。

## 五、兜底方案（借不到两台时）

- 只借到一台：A 段改用「家庭碳积分合并」演示（导出/导入积分包，全程本地可复现），
  分布式同步在 PPT/视频里讲架构与降级设计（分布式 KV + 双通道合并），并注明真机实测待补。
- 全部借不到：AI 段用「扫码录入 + 一句话语义 + 语音」演示（模拟器全支持），
  分布式讲架构；评分会打折但创新点②④仍然成立。
