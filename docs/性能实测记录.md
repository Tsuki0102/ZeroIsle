**零屿 · 性能实测记录**

> 用途：设计方案「测试结果」章节素材。测试环境为模拟器（正式提交前可按同方法在真机复测回填）。

### 测试环境

- 日期：2026-10-01
- 设备：DevEco 本地模拟器（Pura X View 配置，1320×2232 分辨率 480dpi，4 核 4GB RAM）
- 系统镜像：HarmonyOS 6.1.1(24)，API 24
- 被测包：`com.zeroisle.isle` v1.0.0（entry-default-unsigned.hap）
- 测量方法：冷启动取 `hilog` 系统生命周期时间戳（WMS Cold start → Ability onCreate / onWindowStageCreate / onForeground → 页面 onPageShow）；内存用 `hidumper --mem` 取 PSS；体积取 HAP 文件尺寸

### 1. 冷启动耗时（杀进程后冷启动）

- WMS 受理启动请求（Cold start）：20:31:14.966（基准）
- Ability onCreate：20:31:15.443（+477 ms）
- onWindowStageCreate（窗口创建）：20:31:15.574（+608 ms）
- onForeground（进入前台）：20:31:15.612（+646 ms）
- **首帧页面可见（首页 onPageShow）：20:31:16.038（约 1.07 秒）**

结论：模拟器环境下冷启动到首屏约 1.1 秒（含品牌进场动画前段），主线程 onCreate → 窗口创建仅 131 ms，无明显卡顿点。

### 2. 包体积

- HAP 安装包（entry-default-unsigned.hap）：**3.30 MB**（基础版，不含知识库插画）
- 含 12 张知识库插画后：**14.64 MB**（插画原图单张约 1MB，可再压缩至约 2-3 MB 总量，列为后续优化项）

结论：零三方依赖、资源全部本地化（含全部插画与字体子集），体积远低于同类应用平均体积。

### 3. 运行内存（前台，连续操作数分钟后采样）

- PSS Total：约 85 MB（87,141 kB，含图形缓冲、ArkTS 运行时、字体与位图缓存）

结论：主流程（首页/记录/看板/任务/实验室 + 岛灵对话）连续操作后 PSS 保持在 85 MB 量级，无持续增长迹象；Canvas 图表为按需重绘，未发现内存泄漏特征。

### 4. 复测指引

1. 冷启动：force-stop → `hilog -r` → `aa start -a EntryAbility -b com.zeroisle.isle` → 在 hilog 中检索 `Cold start` / `ZeroIsleAbility` / `SPLASH:onPageShow`，取各时间戳差值
2. 内存：`pidof com.zeroisle.isle` 取 PID → `hidumper --mem` 取 PSS Total 行
3. 真机复测建议补充：高帧率模式、连续 5 分钟全页面操作后的 PSS 曲线
